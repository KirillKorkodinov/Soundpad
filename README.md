# Soundpad

Приложение для воспроизведения звука из аудиофайлов

## Особенности

Воспроизведение аудиофайлов прямо из приложения.
Хранение метаданных и структуры библиотеки в SQLite (`sounds_db.sqlite`).
Простой и удобный интерфейс.

## Стек технологий

Python (PyQt6)
QtDesigner
Sqlite

### Требования

Python 3.9 или выше
Установленные зависимости (`requirements.txt`)
